# My Favourite Cricketers Website

A simple, beginner-friendly storytelling website about my favourite cricketers, built using **HTML and CSS**. The page introduces five legendary players, with **Virat Kohli ranked number one**.

## Featured Players

1. Virat Kohli
2. MS Dhoni
3. Rohit Sharma
4. AB de Villiers
5. Sachin Tendulkar

## Technologies Used

- HTML5 — for the webpage structure and content
- CSS3 — for styling, layout, and responsive design

## Project Structure

Keep the files organised like this:

```text
my-cricket-website/
├── index.html
├── style.css
└── images/
    ├── virat.jpg
    ├── dhoni.jpg
    ├── rohit.jpg
    ├── abd.webp
    └── sachin.jpg
```

**Important:** The image filenames and extensions in `images/` must match the paths used in `index.html`.

## How to Run the Website

1. Download or extract the project files.
2. Keep `index.html`, `style.css`, and the `images` folder in the same project directory.
3. Open `index.html` in a web browser such as Chrome or Microsoft Edge.

No installation or build tools are required.

## How the CSS Is Connected

Make sure the following line is inside the `<head>` section of `index.html`:

```html
<link rel="stylesheet" href="style.css">
```

If your HTML file already contains a `<style> ... </style>` block with all the CSS, remove that block when switching to the separate `style.css` file.

## Customisation

- Edit the text in `index.html` to update player descriptions.
- Edit `style.css` to change colours, spacing, fonts, and layout.
- Replace images in the `images/` folder, keeping the filenames the same, or update the image paths in `index.html`.

## Project Purpose

This project is a basic front-end practice project demonstrating HTML page structure, CSS styling, image usage, and a simple scrolling storytelling layout.
